把 AI 比作一个效率很高的助理，提示词（Prompt）就是你给它的工作说明。说明写得越清楚，输出越接近你想要的结果；很多"AI 不好用"的抱怨，其实是说明写得太糊。本文把三块内容串成一条线：先写清楚一条提示词，再按场景取用模板，最后拼成能持续运转的工作流。

## 一、办公提效的误区

先点破两个常见误区。

**误区一：把"问得复杂"当成"问得好"。** 好提示词不是问得多花哨，而是把该交代的交代清楚。一条能用的提示词至少要说清四件事：要它做什么（总结、改写、分析、提炼还是生成）、输出给谁看（领导、客户、同事还是自己）、需要什么风格（正式、简洁、专业还是口语化）、有没有格式要求（分点、表格、段落、字数限制）。这四件事越清楚，结果通常越好。

**误区二：把 AI 当成"问答机器人"。** 问一句、答一句，只是换个花样问问题。更有效的定位是：把 AI 当成一个有稳定交付标准的"外包员工"——给岗位说明书、给参考样例、给修改反馈，再验收它交回来的成果。

为什么值得花力气把说明写清楚？因为困扰很多人的不是"效率低"，而是"流程分裂"：一个人一上午在回消息、做图、写文案、改方案、记账、跟进客户之间来回切换，精力大多消耗在"状态切换"上（也就是任务切换损耗）。AI 能帮的不是把某件事做得更快，而是把某些重复动作"包下来"，让你少切换几次——前提是先把要它接的那件事说清楚。

## 二、Prompt 设计心法

下面五个动作，每个都配一组"错误写法 vs 更好写法"的对照。

### 心法一：先定目标

很多任务做得慢，是因为我们自己也没想清楚目标。

错误写法：

```
帮我总结这份材料。
```

更好的写法：

```
请将以下材料总结成一份适合内部汇报的摘要。要求：
1. 控制在 300 字以内
2. 提炼核心结论
3. 保留关键数据
4. 语言简洁正式
```

### 心法二：给 AI 定角色

同样一段内容，让 AI 扮演办公助理、项目经理、数据分析师、HR 或销售支持，结果会完全不同。

```
请你以一名经验丰富的项目经理身份，帮我整理下面的会议记录。要求：
1. 提炼决策事项
2. 标出待办任务
3. 区分负责人和截止时间
4. 输出适合团队同步的版本
```

角色明确后，输出会更贴近该岗位的表达习惯。

### 心法三：把格式写清楚

抱怨输出不稳定，往往是因为格式没说清楚。只说"帮我分析一下"，输出可能是一大段文字，也可能是一堆零散观点；但给出结构——

```
请按以下结构输出：
1. 结论
2. 依据
3. 风险点
4. 建议
```

它就会尽量按这个框架来。适合办公的框架还有：背景/结论/建议；问题/原因/对策；现状/风险/下一步；摘要/重点/待办；数据/变化/解释/建议。长期重复的工作（周报、月报、会议纪要、客户回复），建议把格式直接固定成模板。

### 心法四：先粗后细

复杂问题不适合一次问完。第一步：

```
请先帮我梳理这份材料的核心结构和重点方向。
```

第二步：

```
请根据上一步的框架，进一步补充每一部分的具体内容。
```

AI 一次处理太多信息容易发散；分两步先定方向、再补细节，更适合长报告和复杂方案。

### 心法五：加约束条件

真实办公里限制条件最重要：不要太口语、不要太长、不要空话、不要重复、要适合发给领导、要适合直接复制使用。

```
请将以下内容改写成适合办公场景的正式文本。要求：
1. 不要超过 300 字
2. 不要出现口语化表达
3. 保留原意
4. 语言简洁，不要堆砌形容词
```

你要的不是 AI 写得"很会说"，而是"能直接用"。

### 一个通用组合模板

把五个心法合起来，就是下面这个可以直接改的模板（骨架可以概括为"角色+任务+要求+案例"）：

```
你现在是一名经验丰富的办公助理，请帮我处理以下内容。
任务目标：【写清楚你要它做什么】
使用场景：【内部汇报 / 给客户 / 给领导 / 团队同步 / 周报等】
输出要求：
1. 语言风格：
2. 字数控制：
3. 结构格式：
4. 必须保留的信息：
5. 不能出现的内容：
原始内容：【粘贴你的材料】
```

一句话概括：不写空泛要求，必须给背景、角色、结构、参考和输出格式。

### 文档处理

**会议纪要精炼**——把两小时的会议录音文本变成重点：

```
请处理下方会议录音文本：
1. 提取 7 个关键决策点
2. 用小学生能懂的话总结 3 个行动项
3. 生成责任表格式：[姓名|任务|截止日]
4. 补充可能遗漏的风险（标注出来）
>>>>> 粘贴文字内容 <<<<<
```

**合同审查**——先让 AI 把可疑的地方拎出来：

```
请审查此合同：
1. 标出 3 个不利条款 + 修改建议
2. 列出 5 个必须补充的细节（标注出来）
3. 用大白话解释第[X]条法律术语
4. 输出修订对比版（旧条款→新条款）
>>>>> 粘贴合同文本 <<<<<
```

**周报**——把流水账整理成有结构的汇报：

```
基于本周工作：
[粘贴工作清单]
- 按价值排序选 TOP3 事项
- 每项包装为"挑战-行动-成果"结构
- 添加数据对比（例：效率提升 37%）
- 结尾埋亮点："下周攻克[痛点]"
```

**公文起草**：

```
起草[通知/函件]：
- 标题："关于[主题]的通知"
- 正文结构：背景→要求→时间节点
- 使用正式公文用语
- 结尾加："特此通知，请遵照执行"
```

**简历优化**：

```
优化我的简历：
[粘贴简历内容]
- 工作经历改用"动词+数据+成果"格式
- 添加岗位关键词：[行业术语1][术语2]
- 生成 3 个不同风格的自我评价（专业/亲和/创新）
```

### 沟通话术

**催款邮件**——专业、有紧迫感，但不撕破脸：

```
写催款邮件，要求：
- 提及合同第[X]条 + 逾期[天数]天
- 专业中带紧迫感
- 隐藏句："如已付款请忽略"
- 结尾附付款码（位置醒目）
- 控制手机一屏内看完
```

**婉拒需求**——用"汉堡包"结构：先肯定价值（"这个需求对[目标]很有帮助"），再说客观限制（"当前资源只能支持[X]工作"），最后给替代方案（"建议先用[简化方案]试运行"）。

**会议救场**——让 AI 生成三句刹车话术：跑题时"回到核心问题，我们是否先确定[X]？"，超时时"为高效推进，可否暂定 A 方案？"，争论时"大家共识是否这三点？"。

**价格谈判**——把"共情—事实—方案"三步固化成回应（"理解您希望控制成本（共情），但[成本因素]导致我们无法让步（事实），可提供[增值服务]补偿（方案）"），并要求输出 3 种应对策略表格。

![会议与谈判救场话术](/images/docs/ai-office-productivity/office-comm-talk.jpg)

**年会主持词**——突然被拉去当主持，需要按时长产出完整串词：

```
写[时长]分钟年会串词：
► 开场白（带公司年度成就数据）
► 节目衔接词（结合节目特点）
► 抽奖环节悬念话术
► 结尾感谢模板（含金句）
```

**怼人金句**——优雅反击职场 PUA，不带脏字但态度明确。常见两种口径，"阴阳怪气版"和"专业防御版"：

```
生成职场反击话术：
阴阳怪气版："您说得对，但我的工资配不上这格局"
专业防御版："根据岗位职责，这不在我OKR范围内"
>> 要求：不带脏字但杀伤力MAX
```

### 数据分析

**表格速读**：

```
分析此表数据：
[描述表格结构/粘贴数据]
1. 找出 3 个异常点 + 可能原因
2. 标记增长最快 TOP3
3. 用对比柱状图呈现[维度A]vs[维度B]
4. 给 3 条改进建议（带实施步骤）
```

**PPT 美化**——注意这里优化的是大纲，不是排版本身：

```
优化以下 PPT 大纲：
[粘贴文字大纲]
- 每页提炼 1 个金句标题（不超过 10 字）
- 数据页添加动态箭头图
- 技术术语旁加"通俗解释"
- 结尾页加互动钩子
```

**行业报告速读**：

```
请总结此报告：
1. 核心结论（1 句话）
2. 3 个关键数据支撑
3. 潜在风险预警
4. 生成汇报脑图（Mermaid 语法）
>>>>> 粘贴报告 <<<<<
```

**竞品分析**：

```
分析[产品]竞品：
- 优势对比表（功能/价格/体验）
- 可借鉴的创新点
- 我们的差异化机会点
- 输出 SWOT 矩阵
```

**用户画像生成**——快速定位目标客户，为某个产品补出可用的受众画像：

```
构建[产品名]用户画像：
► 基本信息：年龄/城市/职业
► 痛点场景：[具体场景描述]
► 消费决策因素TOP3
► 生成虚拟人物卡片（含照片描述）
```

### 时间管理

**日程排布**——把一堆任务交给 AI 排序：

```
优化以下任务安排：
[列出任务+耗时+截止日]
- 按四象限法则分类（重要/紧急）
- 给出最优执行序列（含交通时间）
- 标出可委托事项
- 生成 iCal 格式日历（带提醒设置）
```

**邮件分类**——把收件箱按三档过一遍：紧急待办（需 24h 内响应）、待追踪（标记跟进日期）、可存档（摘要关键信息），并要求输出表格：[主题|发件人|处理建议|DDL]。

还有一批场景化模板，思路一致、按需套用：出差急救包、会议压缩术、专注力拯救计划、学习路径规划、多语言实时翻译、代码调试助手、数据可视化生成、爆款标题生成、活动策划案、短视频脚本、周会暖场游戏、知识库问答机器人（把员工手册丢进去，生成常见问题列表和标准答案）。

## 四、把提示词拼成工作流

提示词单个用只是效率工具；首尾相连用，才有"小团队"的样子。起作用的不是某个提示词有多神，而是它们组合起来覆盖了整条业务链。

### 先做三件事

抄提示词之前，先花一个下午做一次"业务体检"。提示词不是魔法，只是放大器——业务有多清晰，它就能放大多少。

**盘点**：把一周做的事全写下来，大到开会对方案，小到填快递单。要盘点的岗位大致是生产、销售、客服、内容运营、财务、行政。别凭记忆拍脑袋，基础数据不准，后面判断全偏。

**分工**：给每个岗位定一个"AI 接管比例"。一组个人参考值是——内容运营类 70% 以上；客服类 60%，但涉及报价和承诺的环节要人过目；销售类 40%，客户关系越复杂人的参与度越高；财务行政类能自动化就自动化。这是经验值，不是标准答案。

**清边界**：守住三条底线——核心创意的方向性决策不要全交给 AI，它只能给选项、不能替你拍板；客户的聊天记录、账单数据不要直接上传到免费公用 AI 工具；法律、财务、医疗意见 AI 只能辅助起草，最终由有资质的人审核。

### 三条业务线怎么拼

**内容线**：把内容生产做成固定的"内容日"——周一上午先用"账号定位"回顾主线，再把上周的素材、客户高频问题、行业新闻丢给"内容批量生产"，一次生成一周内容池，然后花半小时改语气、剔敏感词，用"公关自查"扫一遍，排期发布。有人说这条线"至少省出每天一小时"，这属于个人体感，不是普适数字。

账号定位：

```
你是一名深耕[细分领域]的资深运营顾问。请根据以下业务信息，输出一份内容账号定位方案。
我的业务是：[一句话说清你卖什么]；目标客户：[年龄、职业、痛点、在哪活动]；差异化优势：[为什么选你]；能稳定输出的内容：[形式与频率]。
请输出：1. 三条内容主线（受众痛点、选题示例、转化路径）；2. 账号人设关键词 3–5 个及语气说明；3. 前 15 条内容的选题日历；4. 发布节奏建议。
要求：不要给"提升内容质量、增加互动"之类的空话，建议必须落到具体动作上。
```

内容批量生产：把一段核心素材改编成小红书、公众号、朋友圈、短视频四个平台版本，并明确要求"各版本保留我的个人语气"，一次产出一周内容池。

**销售线**：把销售链路分段，AI 只干前段和后段。前段的破冰、资料介绍、常见问题解答，让 AI 基于 FAQ 库生成初稿；中段的需求沟通和报价要自己上，AI 顶多帮你生成"客户需求研判"和下一步沟通策略；后段是跟进措辞，可以一次让 AI 给十个版本供你挑。支撑这条线的是客户 FAQ 库：让 AI 当"客户运营专家"，把近期高频问题和你的零散回答一起丢进去，输出"问题类别 → 每题的标准回答（一句话版 + 详细版）→ 注意事项 → 必须转人工的类型"，最后给你一张"常见问题速查表"。

**交付线**：交付最耗时的往往不是做交付物，而是"需求整理"——客户描述零散、口语化、前后矛盾。把原始需求丢给方案生成提示词，它能补全出品牌方向、视觉关键词、受众画像、竞品参考、执行阶段的方案骨架，你再填核心创意和报价逻辑。报价部分只能让 AI 搭格式和话术，数字一定要自己核对。

```
你是一名专业的[行业]方案顾问。请把客户的原始需求整理成一份正式的方案书/报价单框架：1. 客户需求洞察；2. 解决思路（按问题拆解）；3. 交付物清单及时间表；4. 报价明细（表格，标注档位差异）；5. 末尾附"常见疑问解答"。
客户原始需求：[粘贴聊天记录、邮件、需求文档]
我的服务与产品及报价区间：[列清楚产品线和报价范围]
语气要求：专业但不生硬。
```

项目做完，用周报/复盘提示词把过程整理成总结，既是交付物也是经验库。思路同样是"给流水账、要结构"：把本周随手记的事项、客户反馈、数据变化一起丢进去，让它按"核心事项（按业务影响排序）→ 数据变化分析 → 问题与卡点 → 下周行动计划 → 一句话总结"输出，并要求"结论若基于推测就标注推测"，方便你区分事实和推断。

还有一个容易被漏掉的动作是发布前的合规自查：让 AI 以"内容合规审核员"身份，检查广告法极限词、未经验证的效果承诺和他人权益风险，对每条给出严重程度（高/中/低）与替换建议，并按"风险等级 | 原文表述 | 风险说明 | 建议替换"输出表格。涉及功效、承诺、价格对比的内容尤其要过一遍。

还有两个提示词值得知道它们存在：一个是"风格模仿"，先给 AI 三篇你的旧文让它分析用词、句式、语气、结构，再用这个风格写作（注意是模仿你自己的文风，不是拿 AI 去仿冒他人）；一个是"短视频脚本"，让 AI 一次出激进和保守两个版本供你挑。

### 上手的节奏

建议的节奏是：第一周只跑内容线，第二周加销售线，第三周再跑通交付线，跑通一个再上一个。把顺手的提示词按"内容线""销售线""交付线"标好放进备忘录，要用直接复制。

### 再进一步：从单点到小团队

跑通前面几条线之后，下一步的问题就变成：怎么从"体力劳动者"变成真正的"小团队老板"。答案是三步走——先把单点效率扩展成"团队协作"流程（用 AI 产出的第一条内容、第一份方案、第一版脚本都要留档）；再把对接客户的标准化流程往前推；最后用 AI 改造产品形态。下面三节分别展开。

### 数字资产沉淀

第一步落地一个月后，手上会积累一批属于自己的"数字资产"：内容素材库、销售话术库、方案模板库、复盘经验库。这些是"人 + AI"体系里最值钱的东西，因为它们结合了自己的业务特质。

### 标准化流程外推

FAQ 库成熟后，可以把标准动作继续往外推：微信自动回复、电商平台智能客服、私聊前先用 AI 给出初步方案和报价。目标是让客户从"首次接触"到"进入交付"的中间环节几乎不需要本人介入，只在关键节点做决策。

### 产品形态改造

当内容生产、方案制作、客户服务三件事都跑顺之后，一种可能性是：用同样的效率承接过去两倍的客户量，或开发一条全新产品线——把咨询服务打包成标准化课程、把定制方案变成模板产品。这一阶段的形态已经不是"一个人 + AI"，而是"一个人 + AI + 数字工作流"。

这部分结尾强调的观念值得记下：AI 提效不是"让自己变得更快"，而是"让整个业务跑得更顺"——前者只是加速一名工人，后者是重新设计一个组织；一个工人再快一天也只有 24 小时，组织搭好了产能上限远不止于此。它主张的方向不是更压榨自己，而是设计一套即使休假几天也能自动运行的系统。

## 五、落地最容易翻车的坑

提示词之外，真正决定成败的是这几个坑。

**坑一：一次问太多，还不给样例、不说对象、不设长度。** 任务太多 AI 会失焦，建议拆开问；格式要求高就给一个样例，AI 很擅长模仿结构；给领导看和给同事看写法不同，对象要说清楚；不限长度，输出经常过长，而办公场景里简洁通常更重要。

**坑二：AI 一本正经地编数据。** 有人讲过一个这样的教训：他给客户的方案里引用了一个"市场规模增长数据"，看着很专业，发出去前查了一下，发现报告编号查无此物。对策是把规矩定死——凡是具体数字、人名、机构名、报告名、时间线，发布前一律人工核实；一个可行做法是让 AI 在所有数据后加"待核"，再统一查一遍。

**坑三：客户的隐私边界必须主动守。** 有人觉得"反正是我自己客户的聊天记录，给 AI 看一下没什么"，顺手就粘贴进去。推荐的规范是先脱敏：客户名字换成"客户 A"，公司名改成"某连锁餐饮品牌"，电话号码、车牌号删掉，具体报价改成"报价区间"。三步走花不了两分钟，却能把风险挡在门外。

**坑四：AI 写的东西，客户一眼就能看出来。** 典型症状是"官方客服腔"——总是先道歉、总想给你解决问题、总是一个排比接一个排比，客户会直接问"你是机器人吧"。对策是：重要客户的沟通，AI 最多出到"草稿"，个人风格和情绪价值必须自己加。把"您好，非常抱歉让您久等了"改成"刚看到你的消息，不好意思让你等了一会儿"，差别很微妙，但客户能感觉到这是真人在说话。

**坑五：工具越用越多，管理工具的时间比干活还长。** 一听说提效就疯狂注册工具，结果十几个 AI 窗口、不同平台不同会员，还没开始用就嫌烦。建议是先只用一个主对话工具，把上面这些提示词跑通、形成固定工作流之后，再根据痛点决定要不要加工具。

**坑六（内容线专属）：批量生产的同质化。** 连续发几条 AI 生成的内容后，读者会隐约觉得"这个号好像不如以前有灵魂了"。对策是每次批量生成前，必须给 AI 提供本周最新的真实素材——新客户的故事、刚做完的项目、踩过的坑、行业里刚发生的事。


最后提醒一句：以上提示词和效果都来自别人的复盘。真正可信的数据，是你拿一次真实工作、一边用老办法一边用 AI，对照之后自己记下来的那组。
